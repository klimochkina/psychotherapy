# Сайт Кати Климочкиной — GitHub Pages

## Что здесь есть

- `index.html` — весь сайт в одном файле.
- CSS и небольшой JS находятся прямо внутри `index.html`.
- Никакого Tilda, сервера или сборки не требуется.
- Сайт адаптивный: компьютер / планшет / телефон.

## Перед публикацией

В `index.html` найди комментарии:

- `ЗАМЕНИ # НА АКТУАЛЬНУЮ ССЫЛКУ НА ОБУЧЕНИЕ`
- `ЗАМЕНИ # НА СТРАНИЦУ КНИГИ`
- `ЗАМЕНИ # НА СТРАНИЦУ С ПОДКАСТАМИ`
- `ЗАМЕНИ # НА СТРАНИЦУ СО СТАТЬЯМИ`

и замени `href="#"` на реальные ссылки.

## Публикация через GitHub Pages

1. Создай аккаунт на GitHub.
2. Создай новый PUBLIC repository.
3. Назови его, например, `klimochkina-site`.
4. Загрузи в repository файл `index.html`.
5. Открой Settings → Pages.
6. В разделе Build and deployment выбери:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
7. Нажми Save.
8. Через некоторое время GitHub покажет адрес сайта.

Если repository называется `klimochkina-site`, адрес будет примерно:

https://ТВОЙ-GITHUB-USERNAME.github.io/klimochkina-site/

## Если потом захочешь свой домен

GitHub Pages поддерживает собственный домен. Его можно подключить после того,
как базовая версия сайта будет опубликована.

## Важно про формы

GitHub Pages — статический хостинг. Поэтому форма «оставьте e-mail» из Tilda
здесь сама по себе не будет отправлять данные. В этой версии запись идёт через
e-mail и Taplink.

Если позже понадобится настоящая форма, можно подключить внешний сервис форм.
