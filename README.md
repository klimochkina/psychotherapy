# Катя Климочкина — GitHub Pages

Версия v4: переработана сетка и типографика, исправлены пересечения текста, выравнивание и мобильное меню.

## Что изменено
- единая типографика Manrope/Fraunces без случайного смешения шрифтов;
- уменьшен заголовок имени на первом экране;
- hero и CTA больше не наслаиваются;
- секции сделаны компактнее, но с безопасными отступами;
- переходные фразы получили отдельный типографический акцент, цвет и doodle;
- «С чем работаю», «На что я обращаю внимание» и «Для коллег» переведены в более живые асимметричные композиции;
- горизонтальная шкала образования получила фиксированную высоту карточек и безопасные интервалы;
- «Материалы» сохранены как основная визуальная референсная зона;
- из контактов убрана большая чёрная стрелка;
- мобильное меню исправлено.

## Публикация
Загрузите содержимое этой папки в репозиторий GitHub и включите GitHub Pages из ветки с `index.html`.
